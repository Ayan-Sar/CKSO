# Implementation notes, audit and limitations

This document records (1) how each element of the manuscript maps to code, (2) every
choice the manuscript leaves open and what this codebase does, (3) inconsistencies found
in the manuscript while implementing it, and (4) known limitations. Items in (3) should
be resolved in the paper before submission or be stated explicitly in it.

**No experimental numbers from the manuscript are reproduced, asserted, or hard-coded
anywhere in this repository.** All tables must be regenerated by running the scripts.

### Ablation operationalisations (Table V)
* **Row 1, free per-block frequencies (Lusch-style)**: an auxiliary head outputs H subject-conditioned frequencies ω_k = πσ(u_k), initialised at kω̂. The radii stay constrained (the table reports max‖Kˢ‖ = 1.000). HR is read from block 1.
* **Row 2, dense K**: a shared, unconstrained r×r matrix (484 parameters), initialised at 0.9 I + small noise, with powers by repeated multiplication (BPTT). Theorem 3 does not apply. EF is read from the predicted volume trajectory V(Kˢz), s < 64 (hard/soft extremum over frames), with an unrestricted linear readout.
* **Row 3, normal but non-harmonic**: ω_k = κ_k ω₁ with free global κ_k = (H+½)σ(e_k), initialised at κ_k = k. The model is still subject-conditioned through ω₁; the integer lock is removed.
* **Row 4, harmonic lock with non-normal blocks**: B_k = T_k (ρ_k R(kω₁)) T_k⁻¹ with T_k = [[1, η_k],[0, 1]]. This keeps exactly the CKSO eigenvalues (so only normality changes), allows ‖Kˢ‖ > ρ(K)ˢ, and keeps powers closed-form, so the cost comparison is not confounded. Readout: trace mode.
* **Row 5, learned DC**: λ₀ = exp(d), d initialised at 0, deliberately unconstrained.
* **Row 6, no ℒ_freq**: weight 0.

These operationalisations are ours. If the paper's ablations were built differently, adjust `CKSOModel`/`CKSOOperator` before regenerating Table V.

## 3. Inconsistencies / gaps found in the manuscript

1. **Inference parameter count.** The encoder as described (Section III-E) has **225,078** parameters. With the frequency head, readout and operator it comes to **228,110** (0.23 M), and to 453,839 with the decoder (`scripts/complexity.py`). The manuscript states **0.72 M**. The analytic cost, **4.22 GFLOPs** for 64 frames, does agree with the stated 4.1 GFLOPs. Either the architecture description or the parameter count needs correcting.
2. **Operator FLOPs.** One application of a pre-assembled K costs 57 FLOPs (9 two-by-two blocks at 6 FLOPs, plus 3 scalars) for H=5, P=4, Q=3; the manuscript states ≈ 66. The difference depends on what is counted; state the convention.
3. **MI descriptor uses ρ₁₋₃.** In CKSO the ρ_k are *global* learned parameters, identical for every clip, so they carry no per-subject information and cannot help an SVM. We substitute per-clip empirical block moduli \|λ̂_k\| (least-squares one-step fit of each harmonic block of the encoded trajectory, `evaluation.empirical_block_moduli`). The paper must define what ρ₁₋₃ means there.
4. **EchoNet-Dynamic has no heart-rate field.** The public `FileList.csv` contains FileName, EF, ESV, EDV, sizes, FPS, NumberOfFrames and Split, but no HR. Table IV's "header HR" must come from a source the paper names (e.g., original DICOM headers or ECG). The code accepts an external `hr_csv` and otherwise reports HR metrics as unavailable.
5. **CAMUS contains half cycles.** CAMUS sequences run from ED to ES, so assumption A1 (a full periodic orbit) does not hold. The autocorrelation detector has no period to find, and "the same heart must give the same ω₁ in A2C and A4C" cannot be measured from the images without the ECG. Our adapter offers a palindromic ED→ES→ED surrogate (`mirror_half_cycle`), whose "period" is an artefact of the mirroring. The CAMUS cross-view HR experiment needs a defensible protocol before it is reported. Also, depending on the release, CAMUS has 450 or 500 labelled patients; state the version.
6. **HMC-QU has no EF/volume labels.** It is not stated how the volume readout is calibrated on HMC-QU. Pearson r is offset- and scale-invariant but not sign-invariant, and the analytic EF used in the MI descriptor needs a calibrated offset (Appendix C.3). The manuscript also says MI detection uses "no … masks", while the trace correlation needs masks. We provide two options: (a) self-supervised stages only, with the readout uncalibrated; (b) an optional, clearly labelled correlation loss against the mask-derived cavity area (`data.readout_from_masks`, `trace` loss). The HMC-QU masks are LV-*wall* masks, so the cavity is derived by hole filling, with a convex-hull fallback.
7. **EchoNet-Pediatric releases no volumes in mL.** ℒ_vol is unavailable, so the volume offset gauge comes only from the adult initialisation. The fine-tuning protocol (epochs, which stages, learning rate) is not specified. The configs reuse the full curriculum from an adult checkpoint, and the layers whose shape depends on r are re-initialised.
8. **Undefined loss terms**: ℒ_⊥, ℒ_var and ℒ_pos are named but not defined. γ in ℒ_pred and the units of β are also unspecified (see Section 2).
9. **Cost claims for dense K (Section IV-E).** With r = 22, the BPTT recursion through a dense K costs a few 22×22 mat-vecs per step and is negligible next to decoding S frames. In this implementation the decoder (shared by all variants) dominates memory and time, so a 16× slowdown or 24.6 GB for dense K is not expected. Likewise CKSO's own memory grows with S, because ℒ_pred decodes S frames per anchor. Regenerate these numbers with `scripts/stability_experiments.py --benchmark` and report the measured values.
10. **Theorem 3 hypothesis.** "Vanishing transverse modes" holds structurally here, because the gauge-fixed readout has zero weight on transverse/scalar coordinates. The paper could state this, since it turns an assumption into a design property.
11. **Reference numbering** is already flagged in the manuscript; Table I's "[r]" citation for the Koopman AE is a placeholder.

## 4. Verified properties (automated tests, `pytest tests`)

* K is normal; singular values equal eigenvalue moduli; ‖Kˢ‖₂ = 1 for s ≤ 64 under random and extreme raw parameters; all moduli ≤ 1; DC exactly 1.
* Closed-form propagation equals explicit matrix powers (CKSO, non-normal, learned-DC, dense).
* Lyapunov non-increase ‖Kz‖ ≤ ‖z‖.
* Hω₁ < π for every u ∈ ℝ and H ∈ {1, 3, 4, 5, 9}; the Nyquist rule example (H ≤ 3 at 25 fps, 180 bpm).
* Proposition 2(a) gradient formulas for ∂/∂ρ and ∂/∂ω match autograd; ∂ℒ/∂ω₁ = Σ_k k ∂ℒ/∂ω_k.
* The ρ(A) = 0.9, ‖A²‖ > 180 example.
* Theorem 3: the trigonometric trace with decay equals the readout of the propagated latent state.
* Exact root-finding extrema match a 200,000-point grid for H ∈ {1, 2, 3, 5, 8}; critical phases are stationary points; H = 1 closed forms match.
* Soft-extremum bounds hold for β ∈ {2, 10, 40}, N ∈ {16, 64, 256}; soft phases converge to the argmax.
* EF is invariant to scaling, not to offset; the readout ignores transverse/scalar modes.
* The autocorrelation detector recovers integer periods and avoids the octave error a periodogram makes on harmonic-rich traces; the motion-energy surrogate peaks twice per cycle.
* The frequency head outputs ω̂ exactly at initialisation.
* The curriculum schedule (stage boundaries, S 2→48, β 2→40, final weights) matches Appendix D.
* Dataset utilities: delay-window alignment, integer-cycle cropping, patient-wise splits, method-of-disks and polygon areas, wall-mask cavity area; the EchoNet-Dynamic adapter runs on synthetic files in the official format.
* End to end: the four-stage curriculum trains on synthetic clips (CPU), ‖Kˢ‖₂ = 1 at every logged *training step*, and checkpoint → evaluation → CLI scripts all run.

## 5. Limitations of this implementation

* **Not run on clinical data here.** No EchoNet-Dynamic, CAMUS, EchoNet-Pediatric or HMC-QU data was available while writing the code. The adapters follow the public release formats, but column names and file layouts vary by version (especially HMC-QU), so check them on first use. The EchoNet adapter is exercised in the tests on synthetic files in the official format.
* **Baselines are not re-implemented.** Table I/II comparisons require per-video predictions from the published methods. `compare_methods.py` performs the paired test on such files; it cannot use summary numbers.
* **Arrhythmia subgroups** (Section V) need rhythm labels, which EchoNet-Dynamic does not contain; `failure_analysis.py --subgroup-csv` takes them as input.
* **MC-dropout comparison** (Section V) is not implemented: the architecture as described has no dropout.
* **Robustness perturbations** (speckle SNR definition, occlusion geometry) are our definitions; see `ckso/perturbations.py`.
* **Determinism**: `train.deterministic: true` enables deterministic cuDNN/algorithms (`warn_only`). Bitwise reproducibility across GPUs and driver versions is not guaranteed.
* **No mixed precision**: training runs in float32. The trigonometric/log-sum-exp readout was not validated in fp16.
* **Exact readout runs on the CPU** (numpy root finding per clip). This is negligible for H ≤ 9 but makes the inference latency measurement include a host transfer.
* Synthetic data checks the pipeline under assumptions that hold by construction; it says nothing about clinical accuracy.

## 6. Training-dynamics finding on synthetic data (open issue)

Two reduced CPU runs on synthetic clips (64 train / 16 val / 32 test clips, 18 epochs:
A 3, B 3, C 3 with S 2→16, D 9; batch 4; `runs/synthetic_cpu*`) showed the following. These
are pipeline diagnostics on synthetic data, **not** results to report.

* Stages A–C behave as intended. Reconstruction falls, ℒ_lin falls to ≈ 2·10⁻³, the
  learned ω₁ stays at ω̂ (ℒ_freq ≈ 0), and max_{s≤64}‖Kˢ‖₂ = 1 at every logged step.
* As soon as stage D adds ℒ_vol/ℒ_ef, the latent scale grows (harmonic block-1 norm ≈ 4.5).
  With ℒ_lin in absolute units (manuscript form), ℒ_lin then overpowers the bounded ℒ_freq
  and drags ω₁ down to ≈ ω̂/6. The measured weighted gradients on ω₁ were
  ℒ_lin +0.96 vs ℒ_freq −0.62, and ℒ_pred ≈ 0. Test HR error of the learned ω₁: 71 bpm,
  against 1.3 bpm for the autocorrelation detector alone.
* With `loss.lin_normalize: true` (ℒ_lin divided by the detached mean ‖z‖²), the collapse
  stops at ω₁ ≈ ω̂/2. This is the period-doubled optimum the manuscript warns about: octave
  errors occur on 91 % of test clips, i.e. λ_freq = 0.5 did not prevent it here.
* ℒ_pred contributes almost no gradient to ω₁ in these runs. That suggests the decoder is
  not relying on the harmonic blocks, which undermines the identifiability argument for ω₁
  given in Section III-E.
* The EF readout did not learn in 9 stage-D epochs (predictions close to the mean,
  test MAE ≈ 14 pp).

These runs are far shorter and smaller than the manuscript's schedule, so they do not
contradict the paper's numbers. They do show that the ω₁ guard is fragile. Before
running the full experiments, monitor `val.freq` and `freq_disagreement` (both are logged
or reported), and consider:
* `loss.lin_normalize: true`;
* a larger λ_freq in stage D;
* freezing or slowing the frequency head in stage D;
* checking that the harmonic blocks carry image content (e.g. ablate them in the decoder).

Whatever is used must be stated in the paper.
